# 内部 OCR 升级任务回归

范围：同一原创扫描文档应用的 PaddleOCR v2.9.1 → v3.0.0 升级预审。官方资料提供组件事实，应用契约和测试提供自身验收要求。

## 复现

```powershell
python evaluation/internal_upgrade_depth_v1/run_checks.py --output .local-demo-temp/upgrade-task-checks.json
```

`cases.json` 是开发过程中已见的任务回归集，不是独立盲测。`report.json` 记录本次代码、语料和应用文件哈希。脚本检查返回原文是否覆盖规定事实与版本，不调用模型、不评判生成答案、不证明完整业务正确。

## 与真实运行的区别

本次另在开发者控制的 CPU 环境运行作者应用的 `application.pipeline.process`，使用三张原创合成页，并检查输出字段、页号、预期文字和空页。v2.9.1 环境的旧适配入口 3/3 通过；v3.0.0 环境的同一旧入口 0/3，通过异常暴露升级不兼容。单独新版适配器探针 3/3 通过，不能替代应用入口验证。

运行时使用显式本地模型配置；应用工作区未提交，记录以文件哈希绑定，不能称为某个已提交升级分支已通过。运行摘要见 `runtime_summary.json`。详细执行说明见 [内部升级检查](../../docs/internal_upgrade_checks.md)。
