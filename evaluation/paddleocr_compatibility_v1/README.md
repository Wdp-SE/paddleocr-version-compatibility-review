# PaddleOCR 来源派生验收

`cases.json` 在运行策略前冻结，题目与预期片段从两个固定提交的真实资料派生；采用 Top-5，比较 BM25、字段加权与两路 RRF，要求命中文档路径**以及包含预期事实的片段**。它比仅看来源标题严格，但仍是开发者编写的小样本验收，不能当成独立盲测、模型准确率或企业业务效果。

三个原创应用样例验收 API 移除、旧结果消费风险与仍支持的基础调用范围；不是在真实 PaddleOCR 推理环境中运行升级。每个报告显式 `runtime_verified=false`。其他升级组合、动态调用和未收录契约保持未知。

复现：在仓库根目录运行 `python evaluation/paddleocr_compatibility_v1/run_evaluation.py`。报告绑定案例文件、语料清单和应用样例哈希。候选检索策略不因这十题成绩自动替换默认值；还需要业务问题、独立标签和真实生成审查。失败案例保留在报告中，不据此改写问题标签使数字好看。
