# 查询交互验证（2026-10-08）

业务仍为内部研发知识查询与同一原创应用的依赖升级审查。此次修改只涉及前端交互、会话连接复用和示例文案，没有改变官方语料、切分、检索策略或冻结标签。`interview_release_v1/final6` 的规范加载校验仍有效；不能把原 48 题指标解释为这次新题的回答准确率。

## 工程约束

- 工作区元数据缓存限定当前 Streamlit 会话与后端地址，最长 30 秒；用户可点击“刷新知识库状态”。过期或强制刷新失败时清除缓存，不静默沿用 ready 状态。
- 实际查询、检索与 OCR 审查提交前强制刷新状态。知识库身份改变则重新绘制并清除旧证据；服务不可用时不提交。
- 查询区域为局部重运行；页头和导航保留。HTTP 客户端按当前会话和连接配置复用，不跨用户共享。
- 查询设置折叠至操作栏，状态紧贴按钮；只显示真实等待与 elapsed time。完成后滚动至结果，未实现后台分阶段进度或 ETA。
