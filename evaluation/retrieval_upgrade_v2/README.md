# 当前资料的结构检索与真实神经策略对照

2026-10-09 已对当前源码重新冻结、执行并通过来源及成绩重算校验，当前记录在 `final/`。上一轮记录原样移至 `evaluation/archive/retrieval-upgrade-20261008/`。题集已经见过，本轮全部是回归复验。神经策略使用本地已安装资产；免费公网缺少这些资产时显式回退，不把本地重排成绩当公网指标。

业务边界遵守 `docs/business_scope.md`。面向内部研发、测试和应用负责人；PaddleOCR 官方资料代理内部组件知识，原创扫描页 OCR → 归一化 → JSON 应用提供自己的契约。没有企业生产用户数据。

## 实验设计

- 固定当前活动语料，保持原始内容和来源身份。检索前按版本、语言、命名空间和明确模块限定范围。
- 48 条已知回归题；24 条新编、逐原文标注的参数问题，预先分为 12 条验证和 12 条首次封存题。封存题首次只用于锁定策略后的检验，没有据其修改策略。随后发现生成补查丢失结构设置，修复后用原题复验；这些题已经见过，当前复验不能当作新的盲测。首次记录另存 first-sealed-history.json。
- Top-K=5。原始/窗口 BM25 候选 40；结构策略候选 80。结构 BM25 与结构混合检索使用相同结构单位和候选数；窗口与结构对照同时改变分块和候选数，不能把收益全部归于模型。
- 结构单位保留完整参数表行、段落和代码示例；HTML 和链接只在排序表示中清理，引用保留原文精确字符与行号。
- 真正混合检索使用 BAAI/bge-small-zh-v1.5 的神经向量与 BM25，以 RRF 融合；这与多查询 BM25 的 RRF 融合不是同一策略。重排使用 BAAI/bge-reranker-base 的交叉编码器原始分数，不是正确概率。
- 预封存选型规则：零错版本、无模型回退，两类题都不低于原窗口方案；最大化较差题集的完整覆盖率，随后比较两组覆盖率、模块噪声和复杂度。速度不决定本轮选型。

## 指标与可信边界

完整证据覆盖表示 Top-K 中包含该题全部原文证据要求；不是回答准确率、兼容成功率或企业收益。小样本、开发者标注、共享手册仍限制泛化结论。缺失证据、候选生成失败和排序损失逐题保留，不能只公布成功题。

`final/selection.json` 在封存题执行前写入。`final/freeze.json` 绑定源码、资料、数据集和模型资产；`release-lock.json` 绑定最终结果。后端重新核对引用和指标；指纹变化时不展示旧成绩，也不启用旧选型。

本机 Torch CPU 优化内核曾出现 embedding 数值漂移和非有限重排分数。前期 `experiment-*` 是已作废或中止实验，单独留在本机；当前实验改为单线程、关闭 MKLDNN、eager attention，文档向量缓存更换推理身份。`cpu_readiness.json` 记录清除重排缓存后的重复实际计算，不把缓存命中当模型重复性证据。

本地语义模型的路径通过 `PADDLEOCR_EMBEDDING_PATH` 和 `PADDLEOCR_RERANKER_PATH` 指定；请求不会下载模型。模型不可用时有明确降级诊断，不能把 BM25 回退成绩叫神经成绩。模型权重、密钥与缓存不入库。公网需要同样资产和代码才能代表相同链路；这次本地测试不意味着已经部署。

## 重放

使用已有模型资产和包含 sentence-transformers 的服务环境：

1. `prepare.py` 仅用于创建题集，已冻结后拒绝覆盖。
2. `run.py` 对所有配置执行 regression 和 validation；已有文件拒绝覆盖。
3. `publish.py select` 锁定默认候选。
4. 仅对选定候选和 window_bm25 执行 sealed。
5. `publish.py publish` 写入只读发布报告。
6. `verify_tasks.py` 在相同服务链路上执行真实 DeepSeek 的界面问题和三个原创应用 Agent 案例；其结果属于实际冒烟记录，不能由证据覆盖推导回答准确率。

变更源码后应新建实验，不能修改旧锁文件来冒充新测试。

## 生成与审查的限制

部分有出处的陈述不等于完整回答。实际模型回答保留 evidence_gaps，界面醒目标示缺口；补查仍有缺口时不能标记为完全恢复。补查沿用同一自动选型的结构设置，仅一次扩大候选与 Top-K，保留版本、语言、命名空间，不用被拒绝的模型陈述改写检索问题。

Agent 三个演示是同一原创应用的风险、修改后复查和缺失调用层变体。演示可直接运行；使用者仍须检查文件/依赖范围、处置风险、在受控环境完成真实回归并提供负责人确认。零静态风险不等于升级通过，未提交调用层不能得出无影响，未知项不能被模型建议关闭。
