# 内部研发知识查询与升级审查：本轮验证

固定场景见 [business_scope.md](../../docs/business_scope.md)。这是学生 POC，PaddleOCR 真实公开资料代理内部组件知识；当前依赖 v2.9.1，目标 v3.0.0。真实发布者、来源与原创应用身份分别保留。

## 实验设计与可信边界

- 当前语料：60 条固定来源、1768 原文块，另有 3545 个派生检索视图；44 中文 Markdown、11 Python、5 YAML。图片引用尚未提取。
- 48 条查询：24 开发、12 验证、12 分组回归留出；按版本/文件分组。每项事实规定允许来源、适用版本、模块及原文锚点，计分时验证实际检索 span，不只看文件命中。
- 先按开发完整覆盖、非目标模块片段、证据数量排序，再通过验证门槛选方案；随后只报告留出，不按留出重新选参数。速度不参与选型。
- 28 条问题已在前面的诊断中打开；20 条补充问题在最终冻结后首次测量。开发者自行标注，不是业务专家盲测，也不能作为未见企业数据的泛化证明。既有失败记录保存在本目录根层和 `pre-publication-gate/`，不能当作当前发布成绩。
- 五个词法方案与一个本地 BGE 重排方案对照。词法窗口按字符计数，神经方案使用自己的 tokenizer；这是整体表示/策略对比，不能称作同一 tokenizer 下的纯窗口消融。候选 40/80 和 Top-K 5/8 同时变化的方案也不是单变量试验。
- 本机没有此次评测所需的语义 Embedding 资产，未运行神经 dense/RRF；不能以哈希向量替代后宣称评过语义检索。模型失败后的 BM25 回退不计作成功的神经实验。
- 仅评原文必要事实覆盖，不评生成答案准确率、幻觉率或业务影响正确率。此次未进行付费生成、模型规划增益实验及独立专家审阅。

## 审查探针

24 个开发者编写的静态组织变体，包括直接调用、函数/别名/循环、附带消费者、契约/测试资料、跨文件消费者与动态未知输入。部分变体共享骨架，不能按 24 个独立业务任务计算统计显著性。

| 诊断项 | 结果 |
| --- | --- |
| 预期风险位置 | 14 |
| 命中 / 漏报位置 | 12 / 2 |
| 误报位置 | 0 |
| 明确未知输入标记缺口 | 6 / 6 |
| 上述未知探针被判为 unaffected | 0 |
| 未完成的核查点/版本义务 | 78 |

两处已知漏报是跨文件封装返回 OCR 原始结果后，下游进行旧式嵌套索引。关系工具能给出候选，但当前静态规则没有把该值跨文件传递到消费者，因此不能宣称完整结果流分析。零误报只针对这组探针，不代表生产零误报。

78 项未完成属于无模型规划的定向查证诊断：默认长查询未取回完整契约锚点，或动态/配置缺口没有可自动关闭的事实标准。新逻辑如实保留未知，不能把真实但无关的引用当作查证通过。来源锚点覆盖本身也不等于语义结论正确。

测试脚本没有执行待审应用或实际 OCR，也没有运行 LLM 规划；原创三页真实 SDK 回归属于另一项有限运行验证，不能自动套用到这些输入或用户上传应用。

## 复现与发布

`run.py` 创建/核验冻结清单，按 split 和策略运行并保留原始命中；`review_cases.py` 保存具体文件、预期位置与审查报告；`publish.py` 仅在质量门槛及来源重算通过时生成发布记录。完成的冻结文件禁止覆盖，修改源码/语料后必须建立新实验身份并重新验证。

本地 BGE 使用已有资产路径 `PADDLEOCR_RERANKER_PATH`，不通过请求自动下载。权重不随仓库发布；部署时应核对实际模型及回退诊断，不能把本地神经成绩作为公网当前成绩。

最终原始记录在 `final/`。`release-lock.json` 同时比对实验冻结哈希和当前字节，防止对变化后的文件重新生成锁后沿用旧成绩。对选中的神经方案，开发、验证、留出每条都必须有实际成功的重排诊断。

## 最终选型与成绩

选用 `scoped_384`：版本/模块范围约束、384 字符窗口、来源上下文、多查询词法融合，候选 40、Top-K 5。原文及引用不改写。Top-K 用户仍可手动调整；下列成绩仅对应冻结的默认参数。

| 方案 | 开发完整证据 | 验证完整证据 | 分组回归留出完整证据 |
| --- | --- | --- | --- |
| 原始 BM25 / Top-5 | 8/24 | 8/12 | 2/12 |
| 范围窗口 256 / Top-5 | 11/24 | 9/12 | 未用来重新选型 |
| 范围窗口 384 / Top-5（采用） | 12/24 | 10/12 | 7/12 |
| 范围窗口 384 / Top-8，候选 80 | 14/24 | 11/12 | 未用来重新选型 |
| 384 窗口不加上下文 / Top-5 | 12/24 | 7/12 | 未用来重新选型 |
| BGE 384-token / Top-5，含回退 | 15/24，实际重排 22/24 | 未完成，不具选型资格 | 未执行 |

Top-8 在验证集带来 52 条非目标模块片段，高于原始 BM25 的 36 条，未通过噪声门槛；不是为了速度拒绝它。采用方案验证噪声 34 条，分组回归留出 4 条（基线 46 条），三个 split 的错版本片段均为 0。噪声按黄金事实限定模块统计，不是由独立人工判定的语义 Precision。

BGE 开发的 `internal-01` 和 `internal-36` 出现 `RERANK_INVALID_OUTPUT` 并回退词法，因而 15/24 属于混合执行结果，不是稳定神经成绩。开发门槛已经失败后，停止后续神经验证，不按不完整验证结果评价模型效果。没有把不稳定候选设为默认。

采用方案在留出仍漏 5/12 条完整证据（`internal-23/25/28/45/46`）；涵盖官方测试断言、文档预处理输出及文本识别模块结果/输入。全部来源文件可命中，但必要 span 没有全部进入最终证据。这说明数据存在也不保证检索完整，不能称作“准确率已达到企业要求”。冻结这一轮，不再用这五条改词典或选择窗口。

发布保护重算通过，`final/publication-status.json` 为 `promoted=true`；这是本地源码/语料绑定的默认检索选型，未在本轮推送或部署公网。
