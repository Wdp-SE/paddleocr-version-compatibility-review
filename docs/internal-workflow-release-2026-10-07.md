# 内部研发查询与升级审查：本轮交付

业务依据：[固定业务约束](business_scope.md)。用户是内部研发工程师、测试人员与应用负责人；公开演示使用 PaddleOCR 官方资料代理内部知识，不冒充真实企业私有资料。默认原创应用是扫描页 → 中文 OCR → 归一化 → JSON。PPStructure 是相关接口检查分支，未成为默认应用的已验证功能。

## 查询与资料

日常查询默认使用应用当前依赖 v2.9.1，升级查询明确切换 v3.0.0；手动范围仍可选。内部应用发行版本未登记，不把 SDK 版本冒充应用版本。改变查询范围使原结果不再适用；显式问题版本与范围冲突时保留澄清。

活动资料补入两版官方 OCR API 测试源码，共 60 条来源：44 篇中文 Markdown、11 个 Python 文件、5 个 YAML；1768 个原文块。测试源码提供上游断言的参考，系统未执行这些上游测试。两版 setup.py 只有 setup()，没有依赖约束，不作为安装事实补入。继续保留真实发布者、提交、Git blob、SHA-256 与原文行号；144 个图片引用尚未提取，不能据此回答图片内部信息。

这是任务相关知识范围，不能声称公司全部资料已入库。原创应用的设计、输出契约与测试作为应用输入，官方资料作为组件证据，两者保持不同来源。默认输入新增输出契约测试，共 10 个文件。

## 审查流程

1. 明确同一应用、当前/目标依赖、升级目的及提交文件。
2. 静态检查调用位置与受支持的结果流；为代码、下游消费者、设计、配置、依赖清单、契约、测试分别标注角色。不要求每个消费者文件都导入 OCR。
3. Agent 调用同一 RAG，先验证来源，再按每个核查点与版本判断契约锚点是否覆盖。锚点覆盖不是语义正确率，未知核查点继续保留候选状态。
4. 输出静态发现、候选关系、证据缺口及针对规则的回归要求。旧结果消费检查文本/得分映射与 JSON；结构迁移分支检查区域/表格字段与输出契约。
5. 工程师逐项填写风险处置理由；无法解析的关系或资料缺口须显式记录残余风险。
6. 在授权开发环境自行修改、执行测试，填写导出的外部回归模板：实际依赖、环境、输入条件、契约检查及日志摘要。文件或报告变化时，旧记录绑定失效。
7. 人工记录继续升级流程或暂缓。已审阅报告与升级处置是不同事件。SQLite 保存追加快照并提供 JSON 导出，不执行应用、不修改上游、不自动批准升级。

外部记录是匿名用户提交，系统没有认证运行真实性。即使填写全部通过，静态报告的 runtime_verified 仍为 false，不能宣称实际部署兼容。

## 验证方法与边界

实验比较原始 BM25、256/384 字符窗口、上下文补齐、候选/Top-K 扩大与本地 BGE 重排。神经方案使用其真实 tokenizer 计数，与字符窗口属于整体方案对比，不能当成单独窗口大小消融。开发集选型、验证集设门槛、留出只报告；已打开的问题后续作为回归，不能再次称为未知盲测。每条必要事实核对真实版本与来源，不只看来源文件命中。

指标区分原文事实覆盖、静态风险规则表现、运行兼容性和生成答案正确率。没有独立专家标注与实际用户数据，不报告企业准确率、零幻觉或真实 ROI。新资料/代码使旧发布成绩失效；只有冻结源码、语料与成绩绑定校验通过后才展示新成绩。

本轮运行记录及失败项见 [验证说明](../evaluation/internal_workflow_v1/README.md)。未在本轮推送 main 或更新公网。

## 最终验收记录

冻结 48 条查询（24 开发、12 验证、12 分组回归留出），当前选用范围 BM25、384 字符窗口与上下文补齐，候选 40、Top-K 5。完整证据覆盖分别为 12/24、10/12、7/12，原始 BM25 对照为 8/24、8/12、2/12；错版本均为 0。回归留出的非目标模块片段从 46 降至 4。不是回答正确率；这批自标题也不是独立专家盲测。

扩大 Top-K 的候选噪声增加而未通过验证门槛；本地 BGE 开发 2/24 次出现无效输出回退，不能把混合结果当稳定重排提升，因此被排除。最终发布记录已通过冻结哈希和原文成绩重算。

24 个静态组织探针预期 14 处风险，定位 12 处，漏报 2 处跨文件消费者，误报 0；6 个明确未知探针都保留缺口。无模型规划的核查还有 78 项版本义务未完成，不能宣称端到端 Agent 准确率。模型规划收益、生成答案正确性与用户应用运行尚未完成独立验收。

完整代码回归：服务 451 passed / 1 skipped；Agent 183 passed；UI 184 passed / 10 skipped。新策略激活后 API/证据/冻结保护定向回归另有 21 passed；真实 TestClient 工作区与检索端点均 HTTP 200，实际采用 contextual_bm25、384 字符、40 候选、5 条 v2.9.1 证据。重要独立审查问题已修复：证据累积、冻结身份绑定、神经回退误标。没有执行上传代码或自动批准升级。
