# 内部应用提交审查

目标用户是内部研发、测试与应用负责人。当前登记的是学生原创扫描文档应用，PaddleOCR 官方公开资料继续代理内部组件知识；两者保留各自身份。

## 使用步骤

1. 进入“发起兼容性审查”，默认选择“已登记应用（Git 提交）”。
2. 选择登记应用。升级前预审填写当前应用提交，默认 `HEAD`；候选提交审查同时填写基准与候选提交。这里使用服务器已有的本地分支、完整 SHA 或普通祖先引用，不接受 GitHub URL、PR URL或任意仓库路径。
3. 点击“读取提交与检查范围”。页面显示解析后的完整提交、收集清单和缺口。工作区中未提交的修改不会进入审查；分支移动后也不会悄悄替换已装载的提交，需重新读取。
4. 可先查询本次应用提交的契约和测试原文，再点击“审查应用兼容性”。候选模式分别分析基准、候选的完整登记上下文，包含未修改的消费者；对照是按规则与文件比较，不是逐语句修复认证。
5. 根据发现修改代码、补资料或在开发环境运行回归。重新选择修改后的提交进行审查，再下载该报告的回归模板。填写模板的 `application_commit` 必须与实际测试提交及当前报告一致；SDK 实际版本也必须与目标一致。
6. 下载报告、恢复凭据与外部回归记录。恢复时先装载相同应用提交与设置，再输入任务编号和凭据。代码、范围登记、语料、服务或流程策略变化后会拒绝旧任务复用。

系统不执行提交代码、不拉取任意仓库、不创建修改或批准升级。测试文件只代表测试定义，人工导入日志只代表提交者声明，均不自动成为服务认证的运行成功。

## 应用登记

管理员维护 `config/internal_applications.json`；浏览器仅能选择登记 ID。仓库路径相对登记文件所在目录解析，应用根目录及包含/排除范围必须由维护者指定。当前包含 `application/` 与 `result_adapter.py`，覆盖调用层、归一化、适配器、消费者、输出契约、设计、依赖清单与测试。

登记的必需角色采用存在性检查；它不证明资料内容完整或依赖图完整。收集预算仍为最多 12 个文件、单文件 50 KB、合计 200 KB、每文件 5000 行。缺少角色、超预算、链接、子模块、非支持格式或无法解析的路径会留下缺口。被登记规则排除的内容不在本次检查范围。暂不支持自动扩大到任意大仓库。

Git 读取使用固定参数的只读对象命令，先将引用解析成不可变提交，不 checkout、不运行钩子、不应用过滤器、不下载子模块。Windows 所有者差异仅对服务器登记目录使用单次命令的精确 `safe.directory`，不修改全局配置。

`requirements-v2.txt` 与 `requirements-v3.txt` 是示例环境声明。收集到它们不表示候选环境已经安装或运行相应依赖。应用提交与 SDK 发布版本始终分开管理，当前没有虚构内部发行版本。

## 两类证据

- 官方知识：固定 PaddleOCR v2.9.1/v3.0.0 来源，用于组件接口、参数与迁移事实。
- 应用知识：`/public/application-search` 只在本次请求的应用快照内做 BM25 原文检索，保留应用提交、文件哈希及行号。调用端再次核对原文、范围与提交。它不混入官方索引，不用于证明 SDK 官方行为，也不证明测试已经运行。

应用知识检索当前提供可核对原文和审查上下文，尚未实现对内部资料任意问题的完整生成问答。跨函数实参传播、动态分派和条件控制流仍有静态分析盲区；登记范围收集完整不能消除这些盲区。当前正式登记快照可能返回“需补充验证”，不能改写成已确认无风险。

## 任务留存与恢复

任务结果与成功查证响应保存在 UI 运行目录的 `application_tasks.sqlite3`。恢复凭据使用随机令牌，数据库仅存令牌哈希；没有企业登录、项目 ACL 或实名审批功能。凭据持有人可取回对应记录，因此应妥善保管。

服务进程重启后，旧进程运行中的任务在读取时标为 `INTERRUPTED`。不会在启动时自动调用模型。身份一致时显式重试可复用保存的检索、文档、规划和建议响应；失败的调用不缓存。没有完成的在途请求、静态检查和未持久化步骤需要重新处理。缓存不是完整逐指令恢复，也不提供跨实例任务调度。

当前每个数据库最多 1000 个任务，每任务最多 100 条缓存，报告最多 5 MB，单条缓存最多 1 MB。达到上限需管理员维护；没有自动迁移、备份或归档服务。Streamlit 临时磁盘重建仍可能丢失记录，正式部署需要持久卷、身份权限及访问审计。

## 实际内部试用前的缺口

第一版实现一个已登记应用和本地 Git 输入方式。PR webhook、远程仓库凭据管理、企业账号、按资料过滤的项目权限、可信 CI 日志认证尚未实现。公网入口只用于公开和学生原创资料演示，不能接入企业私有仓库或发送真实内部资料给外部模型。后续试用须先落实身份、授权、模型数据出口、持久存储与真实任务验收。
